## STACK 
Se implementa como stack principal: En el backend NestJs, React y Vite con Typescript como lenguaje en el frontend, PostgresSQL como BD (probablemente en pricipio se utilice SQLite).
Como agregados implementamos Redux en frontend y React Router, Prisma como ORM en la BD, JWT+refresh tokens para manejar Auth, para estilar probablemente Boostrap 
Se comienza el proyecto como un Monolito Modular, posteriormente puede crecer para implementación de microservicios utilizando Docker, Kubernets, Redis y Kafka o RabbitMQ para comunicación asíncrona entre servicios. CI/CD con Github Actions
